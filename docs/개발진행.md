- **사용자 재지적 "확대·축소할 때마다 그래프가 덜덜 떨림, 더 자연스럽게" (11/07 오후)**. 앞의 수정은 다시 맞추기만 막았고 원인이 더 있었다:
  1. 배율이 한 프레임에 0.1씩 뜀 → `ZoomScope`를 180ms 애니메이션(`TweenAnimationBuilder`, easeOutCubic)으로
  2. 배율 1.0일 때만 감싸는 위젯을 빼서, 1.0↔1.1을 지날 때 그 아래 화면 전체가 새로 만들어짐(그래프 위치를 잃고 다시 맞춤) → 배율 1이어도 구조 유지
  3. 영역 크기가 바뀌면 그래프가 왼쪽 위 기준으로 남아 가운데가 밀림 → `GraphView._keepCenter`(바뀐 크기의 절반만큼 같은 프레임에 옮김)
  4. 회귀 시험이 **빈 통과**였다: 시험 창이 좁아 배율 제한 때문에 ⌘+가 아무 일도 안 함 → 창을 1600×1000으로 맞추고 16ms마다 배율을 재 "중간 프레임 4개 이상·한 방향"과 "그래프 가운데 움직임 1px 미만"을 확인
- `BRAIN_CONFIG` 환경변수: `AppConfig.path`가 이 값을 먼저 씀. `zoom_test`는 없으면 멈춤. 시험 뒤 사용자 설정 그대로(0.9) 확인
