### 인텔 맥 지원 계획 (O-8, 11/12 — 계획만, 하지 않음)

- **지금**: 앱 안 프레임워크는 x86_64·arm64 두 벌이라 앱은 인텔 맥에서도 켜진다. 앱에 묶인 `brain`(`assets/brain/bin/brain`)은 arm64뿐이다(`file`로 확인). 그래서 인텔 맥에서는 검색·색인·Claude Code 연동이 모두 안 된다.
- **이 맥에서 인텔용 `brain`을 못 만드는 까닭** (11/12 확인): Dart 3.13.7 `dart build cli --target-os macos --target-arch x64`가 "Unsupported target platform macos_x64"로 거절한다. 교차 빌드는 linux 대상만 된다. 이 맥에는 macOS용 Rosetta도 없다(`arch -x86_64` → Bad CPU type).
- **지원하기로 하면 할 일**:
  1. 인텔 macOS에서 `dart build cli`를 돌린다. 인텔 맥 한 대나 인텔 CI 실행기가 필요하다. GitHub Actions의 인텔 macOS 실행기가 아직 있는지는 미확인(배경지식)이다.
  2. `lipo -create`로 arm64·x64를 한 파일로 합친다. `sqlite3` 동적 라이브러리도 두 벌을 합쳐야 한다.
  3. `tool/release.sh`의 소스 해시 확인을 두 아키텍처 모두에 맞게 바꾼다.
  4. 인텔 맥에서 [연동] → `brain find`가 도는지 확인한다.
- **지원하지 않기로 하면**: `flutter config --enable-macos-arm64-only`로 앱을 arm64만 빌드한다(약 −25MB, 추정). 홍보 페이지에 "Apple Silicon(M1 이상) 전용"이라고 적는다.
- **정할 때**: .dmg 배포 전. 그때까지 홍보 페이지·발표에서는 인텔 맥 지원을 말하지 않는다.
