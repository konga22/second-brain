# 세컨드 브레인 설치 안내

설치 파일 `SecondBrain-<버전>.dmg`로 처음 설치하는 순서다. 만드는 법은 맨 아래 "만드는 쪽"에 있다.

## 필요한 것

- **Apple Silicon(M1 이상) 맥, macOS 14 이상.** 앱 화면은 macOS 12부터 열리지만, 검색·연동에 쓰는 `brain` 프로그램이 arm64·macOS 14 이상용이다(`otool -l`의 `minos 14.0`, 11/12 확인). 인텔 맥은 아직 안 된다(개발진행 "인텔 맥 지원 계획").
- Claude Code와 연동하려면 Claude Code가 설치돼 있어야 한다(`claude` 명령).

## 설치

1. `SecondBrain-<버전>.dmg`를 연다.
2. 열린 창에서 **세컨드 브레인** 아이콘을 **Applications** 폴더로 끌어 놓는다.
3. 응용 프로그램 폴더에서 **세컨드 브레인**을 연다. 처음에는 "Apple에서 확인할 수 없음" 경고가 뜨고 열리지 않는다. 경고 창에서 [완료]를 누른다.
4. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래 **보안** 칸의 "세컨드 브레인이(가) 차단되었습니다" 옆 **[그래도 열기]**를 누른다. 맥 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 **[그래도 열기]**를 누른다.
5. 한 번 열고 나면 다음부터는 그냥 열린다.

이 경고는 앱이 Apple 개발자 서명·공증을 받지 않아서 뜬다(기말 프로젝트라 유료 개발자 계정이 없다). 앱 안에 서명 자체는 있어 "손상됨"으로 나오지는 않는다. 출처: Apple 사용 설명서 [확인되지 않은 개발자의 Mac 앱 열기](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac). macOS 15부터 Control-클릭으로 여는 옛 방법은 막혔다고 알려져 있다(미확인, 배경지식).

## 처음 쓰기

1. 앱이 지식 폴더(`~/SecondBrain`)를 만든다. 다른 폴더를 쓰려면 설정에서 고른다.
2. 왼쪽 **연동** 화면의 Claude Code 칸에서 [연동]을 누르면 Claude Code 플러그인과 `brain`이 깔린다.
3. Claude Code를 새로 열고 "내 노트에서 ○○ 찾아 줘"처럼 물어 `brain find`가 도는지 본다.

## 지우기

응용 프로그램 폴더에서 앱을 휴지통으로 옮긴다. 지식 폴더(`~/SecondBrain`)는 사용자의 md 파일이라 지우지 않는다. 플러그인은 연동 화면 [해제] 또는 `claude plugin uninstall second-brain@second-brain-local`.

## 만드는 쪽

```bash
bash tool/release.sh     # 정식 빌드 (앱 서명을 다시 봉인하고 검증한다)
bash tool/make_dmg.sh    # → dist/SecondBrain-<버전>.dmg
```

- 11/12 확인(이 맥, macOS 27.2): 내려받은 것처럼 격리 표시를 붙인 `.dmg`를 붙여 앱을 복사하면 격리 표시가 앱까지 옮겨 붙고, `codesign --verify --deep --strict` 통과, `spctl`은 `rejected`(ad-hoc 서명이라 예상대로 → 위 4번 [그래도 열기]가 필요). 34MB.
- 그전 빌드는 앱 겉 서명이 안쪽(App.framework)과 맞지 않아 `nested code is modified or invalid`였다. 내려받은 앱이 이러면 "손상됨"으로 열리지 않으므로 `release.sh`가 겉을 다시 봉인한다.
- 아직 못 한 것: 새 사용자 계정(또는 다른 맥)에서 실제로 [그래도 열기] → [연동] → 첫 질문까지. 내려받을 곳: 홍보 페이지(Cloudflare Pages)는 파일 하나 25MiB 한도라 34MB `.dmg`를 못 올린다.
