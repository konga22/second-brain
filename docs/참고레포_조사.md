# 참고 레포 조사 — 홍보 웹·데스크톱 앱·디자인·백엔드·유사 프로젝트

- **조사일**: 2026-11-05 (별·라이선스·최근 커밋은 GitHub API로 확인)
- **상태**: 후보 목록. 실제로 쓰기로 한 것만 [설계서](설계서.md) 11절에 출처·라이선스를 옮긴다.

## TL;DR

- **홍보 웹**은 Flutter가 아니라 **Astro + Tailwind**로 만든다. 첫 화면이 빠르고 검색에 잘 걸린다. 웹은 홍보 페이지만 두고 Flutter 웹 체험판은 만들지 않는다 (2026-11-05 결정, 설계서 v1.2).
- **디자인**은 앱(`shadcn_ui`)과 웹(`shadcn/ui`)이 같은 디자인 언어를 쓴다. 교수님 레포(`shadcn_ui_plus`, `lucide_icon_pack`)도 같은 계열이다.
- **데스크톱 앱**은 LocalSend 구조를 참고하고, 창·파일 끌어놓기·배포는 leanflutter 계열 패키지로 해결한다. 코드를 복사해도 되는 건 MIT·Apache·BSD뿐이고, AGPL(AppFlowy, basic-memory)은 화면·구조만 본다.
