# 신규 버전(프롬프트 이후) 사용 후기

- **쓰는 사람**: 개발을 맡은 AI(Claude Code)가 이 저장소 작업 중에 세컨드 브레인을 실제로 쓰면서 적는다. 사용자 요청(11/13).
- **목적**: 시험 숫자 말고, 실제로 써 보니 좋았던 점·불편한 점·이상한 점을 남겨 다음 고칠 거리로 삼는다.
- **원칙**: 지식 내용(노트 제목·본문)은 여기 옮기지 않는다(이 문서는 GitHub에 올라간다). 노트는 번호로만 가리킨다.

### 새 판을 써 보며 (읽기만)

- `brain find`의 "확인 전 초안 N개 있음" 안내는 결과가 0개일 때만 나와 평소에는 조용하다. 다만 사용자가 방금 저장한 초안을 바로 찾으면 AI는 "확인 전 초안이 있다"만 알 수 있다 — 정리 보드에서 확인해야 한다는 것을 사용자에게 알려야 한다.
- `brain doctor`는 원격 없는 지식 폴더에서 조용했다(4.6).
