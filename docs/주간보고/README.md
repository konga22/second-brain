## 파일

| 파일 | 언제 쓰나 |
|---|---|
| `작업일지.md` | 작업한 날마다. 한 일, 바뀐 것(설계·코드), 문제, 다음 할 일 |
| `피드백기록.md` | 교수님 피드백을 받은 날. 받은 내용, 대응, 반영 위치, 상태 |
| `원본/<회차>.js` | 보고일 전날. 작업일지·피드백 기록·커밋 기록을 모아 보고서 내용을 쓴다 |
| `주간보고_<회차>_김민상.docx` / `.pdf` | `make.sh`가 만든다. 교수님께는 PDF를 보낸다 |

## 보고서 목차 (매주 같음)

1. 요약
2. 일정 현황
3. 이번 기간 한 일
4. 수정 내역 (설계 변경, 코드 변경)
5. 피드백 반영 현황
6. 문제와 대응
7. 다음 7일 계획
8. 확인 요청 사항

## 만들기

```bash
bash docs/주간보고/make.sh 00_기점
```

새 회차는 바로 전 회차 원본을 복사해서 고친다. 예: `원본/01_1주차.js`. Word·PDF 생성기는 기획안과 같은 `docs/기획안_원본/build.js`를 쓴다.
