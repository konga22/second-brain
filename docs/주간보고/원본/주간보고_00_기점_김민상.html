5. 피드백 반영 현황

#피드백대응상태
1사용자 AI가 읽으면 임베딩이 필요 없는데 왜 서버를 거치나, 명칭경로 A·B 분리, 임베딩 제거, "AI 게이트웨이"로 변경설계 반영
2색인 알고리즘SQLite FTS5 + BM25, 한글 2글자 분할설계 반영
3웹 IndexedDB는 느림macOS 데스크톱을 본 제품으로, 웹은 홍보 페이지로설계 반영
4md 파일이 많아지면 문제 (RAG·raw RAG)색인, 계층 목차, 원본(raw) 분리, 중복 합치기설계 반영
5.claude·.codex 파일로 온보딩연동 버튼으로 스킬·훅 설치, 사용자 요약 자동 주입설계 반영
6CLI로 작동하나 (토큰 최적화)brain CLI, 기본 출력 5줄설계 반영
7교정은 검증 에이전트로 (RSI 언급)점수 규칙 제거, 검증 에이전트, diff와 회귀 시험으로 검사 기준 개선설계 반영
8gbrain·claude-mem·ECC 비추천, 차별성참고 자료 정리, 공식 기능과 비교설계 반영
9직접 만든 스킬을 참고 자료로연동 스킬 제작, 결과 보고서 첨부진행 (3주차)

"설계 반영"은 설계서에 들어간 상태다. 3·4·7번은 설계 전체 검토에서 이유와 방법을 한 번 더 보완했다(설계서 v1.3 부록 A). 실제 구현은 2절 일정에 따라 1~4주차에 진행하고 매주 보고한다.
