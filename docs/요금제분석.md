# 요금제 분석과 추천 (2026-11-07)

- **질문**: 지금 요금제(가안)가 적자가 아닌가, 마진까지 따져서 추천 요금제를 내라 (사용자 11/07)
- **결론 (11/08 최종 추천, 사용자 결정)**: **AI 크레딧**으로 센다 — 1크레딧 = API 원가 1원, 서버가 실제 입력·출력 토큰 × 모델 단가로 뺀다. **무료 월 60크레딧 / Pro 월 12,900원(연 129,000원)·월 3,000크레딧.** Haiku 5.5로 질문+검증 약 1,160회. 크레딧이 곧 원가 상한이라 어떤 모델로 바꾸든, 다 쓰든 **Pro 마진 최소 8,245원(70%)**. 무료 1,000명일 때 Pro 10명이면 손익분기 (7절).
- **거쳐 온 안**: 6,900원·질문 500회(3절, 버림) → 12,900원·질문 200회(6절, 비싼 모델이면 마진 7%라 버림) → 크레딧(7절).
- **바꾼 이유**: 교수님 피드백 "지금 요금제(9,900원)는 적자"(피드백기록 10). 처음 추천(6,900원, 3절)은 값을 더 낮춰 방향이 틀렸다 — 사용자 한 명당은 남아도 손익분기에 필요한 유료 사용자가 늘고, 비싼 모델로 바꾸면 바로 적자다. **적자의 핵심은 "질문 월 1,000회"라는 한도**였다(비싼 모델 기준 질문 1회 약 26원 × 2호출 × 1,000회 = 52,000원).
- **상태**: 추천안이다. 확정은 [설계서 미결정 5](설계서.md#7-미결정-사항) — 사용자·교수님 확인 뒤.

## 2. 지금 가안은 왜 적자인가

지금 가안: 무료 AI 질문 월 50회 / Pro 월 9,900원, AI 질문 월 1,000회 + **검증 하루 200회**.

| Pro 사용자 한 명 (월) | 호출 수 | API 원가 | 실제로 남는 매출 | 마진 |
|---|---|---|---|---|
| 한도까지 다 씀 | 질문 1,000 + 검증 6,000 = 7,000회 | 9,100원 (보수 18,200원) | 8,630원 | **−470원 (보수 −9,570원)** |
| 보통 사용 (질문 150 + 검증 50) | 200회 | 260원 | 8,630원 | 8,370원 (97%) |

- 남는 매출 = 9,900원 − 부가세(÷1.1 → 9,000원) − 카드 수수료(9,900원 × 3.4% × 1.1 = 370원) = 8,630원
- **적자의 원인은 검증 한도**다. 검증은 질문을 고칠 때만 필요한데 하루 200회(월 6,000회)를 열어 두어, 질문 한도(1,000회)의 6배까지 쓸 수 있다.

- **값을 9,900원 → 6,900원으로**: 이 서비스의 핵심(경로 A 연동, 그래프, 실수 노트)은 우리 원가가 0원이라 값을 낮춰도 마진이 남는다. 비교 대상은 Obsidian Sync(월 $4대), Notion AI·Mem 같은 AI 메모(월 $8~10)다. 한국 학생·개인 개발자가 부담 없이 쓰는 1만 원 아래로 두고, 연 결제를 두 달 싸게 해 이탈을 줄인다.
