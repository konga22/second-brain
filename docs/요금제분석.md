## 2. 지금 가안은 왜 적자인가

지금 가안: 무료 AI 질문 월 50회 / Pro 월 9,900원, AI 질문 월 1,000회 + **검증 하루 200회**.

| Pro 사용자 한 명 (월) | 호출 수 | API 원가 | 실제로 남는 매출 | 마진 |
|---|---|---|---|---|
| 한도까지 다 씀 | 질문 1,000 + 검증 6,000 = 7,000회 | 9,100원 (보수 18,200원) | 8,630원 | **−470원 (보수 −9,570원)** |
| 보통 사용 (질문 150 + 검증 50) | 200회 | 260원 | 8,630원 | 8,370원 (97%) |

- 남는 매출 = 9,900원 − 부가세(÷1.1 → 9,000원) − 카드 수수료(9,900원 × 3.4% × 1.1 = 370원) = 8,630원
- **적자의 원인은 검증 한도**다. 검증은 질문을 고칠 때만 필요한데 하루 200회(월 6,000회)를 열어 두어, 질문 한도(1,000회)의 6배까지 쓸 수 있다.

## 3. 추천 요금제

| | 무료 | **Pro (추천)** |
|---|---|---|
| 값 | 0원 | **월 6,900원** (연 69,000원 = 두 달 무료) |
| Claude Code·Codex 연동 (경로 A) | 무제한 | 무제한 |
| 앱 안 AI 질문 | 월 30회 | **월 500회**, 하루 50회까지 |
| 검증 (틀렸어 → 실수 노트) | 질문 1회에 1번 포함 | 질문 1회에 1번 포함 |
| 노트·실수 노트 | 200개·20개 (안내만, 막지 않음) | 제한 없음 |
| 가져온 대화 자동 묶음 이름 | - | 포함 |

**왜 이렇게 바꾸나**

- **검증을 질문에 묶는다**: 검증은 "AI 답을 고칠 때" 쓰므로 질문보다 많을 수 없다. 따로 한도를 주면 원가 상한이 사라진다.
- **하루 상한 50회**: 한 사람이 하루에 한 달 치를 다 쓰는 남용을 막는다.
- **값을 9,900원 → 6,900원으로**: 이 서비스의 핵심(경로 A 연동, 그래프, 실수 노트)은 우리 원가가 0원이라 값을 낮춰도 마진이 남는다. 비교 대상은 Obsidian Sync(월 $4대), Notion AI·Mem 같은 AI 메모(월 $8~10)다. 한국 학생·개인 개발자가 부담 없이 쓰는 1만 원 아래로 두고, 연 결제를 두 달 싸게 해 이탈을 줄인다.

**사용자 한 명당 마진** (남는 매출 = 6,900 ÷ 1.1 − 6,900 × 3.4% × 1.1 = 6,015원)

| Pro 사용자 한 명 (월) | 호출 수 | API 원가 | 마진 | 마진율 (부가세 뺀 매출 6,273원 기준) |
|---|---|---|---|---|
| 한도까지 다 씀 | 질문 500 + 검증 500 = 1,000회 | 1,300원 (보수 2,600원) | **4,715원 (보수 3,415원)** | 75% (보수 54%) |
| 보통 사용 | 200회 | 260원 | 5,755원 | 92% |
| 무료 사용자 한 명, 한도까지 | 60회 | 78원 | −78원 | - |
| 무료 사용자 한 명, 보통 (월 10회) | 20회 | 26원 | −26원 | - |

**손익분기 (고정비 월 55,400원)**

| 무료 사용자 | 무료 원가 (보통 사용) | 필요한 Pro 사용자 (최악 마진 기준) | 전환율 |
|---|---|---|---|
| 100명 | 2,600원 | 13명 | 13% |
| 1,000명 | 26,000원 | **18명** | 1.8% |
| 10,000명 | 260,000원 | 67명 | 0.7% |

- 무료 사용자가 많아져도 경로 A는 원가가 0원이라 무료 비용이 작다. 1,000명일 때 Pro 18명(1.8%)이면 손익분기다.
- 처음 한 번 드는 토스페이먼츠 가입비 22만 원은 Pro 47명이 한 달 내면 회수된다.
